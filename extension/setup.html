Connect Chat Commander in ChatGPT

Use your own private tunnel and personal ChatGPT profile. Installing this extension does not grant access to OpenAI tunnel or custom MCP features.

1. Prepare the connection key

Create a private OpenAI tunnel associated with your personal ChatGPT workspace and a dedicated runtime key. Tunnel management requires Read + Manage; selecting/running requires Read + Use. Enter the ID/key only in extension step 1, then save. Optional encryption uses a separate local password.

2. Pair the tab

Open and sign in to ChatGPT. In extension step 2 allow access, choose the intended loaded tab and connect it. Read the feedback below that button. Keep the tab open. Pairing is separate from saving the key.

3. Add the custom app in ChatGPT

  1. Open Plugins/Apps → + → Add custom MCP server (older UI: developer-mode Create app). Enable developer mode first if your workspace requires it. If unavailable, check your eligibility.
  2. Name: Chat Commander. Connection: Tunnel. Select or paste the same tunnel ID. If missing, verify workspace association and Read + Use permission.
  3. App-level authentication: No authentication for this private personal server. It has no OAuth service. Never put your runtime key in a chat or OAuth field.
  4. Review the warning and create the connection. Keep it private: anyone who can invoke this workspace app/tunnel may be able to access your paired history.
  5. After extension updates, open the app management page and choose Refresh tools. Check that prepare_project_plan is listed and enabled. Start a new conversation and select Chat Commander again; extension reload alone does not refresh the callable catalog.
  6. Enable Chat Commander in a command conversation and run the read-only prompt below.
Use Chat Commander to list my 3 most recent chats. Do not modify anything.

The list or error appears in ChatGPT. Extension step 3 separately shows the observed catalog fetch and successful tool call. Polling and a saved key alone are not end-to-end success. No manual acknowledgement is required.

After a restart

Unlock the saved key, open the signed-in tab, then wait for same-account reconnection or explicitly pair again. Invoke a read to verify the tool path. Every write still requires its exact confirmation card.

Text read from source chats may remain in command-chat history after source deletion. Uncertain writes must not be retried blindly. Reconnection revokes approvals; same-account reports remain in worker memory until expiry or capacity eviction. Restart loses reports; forget purges them.
