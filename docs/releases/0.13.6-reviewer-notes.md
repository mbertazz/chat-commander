Chat Commander 0.13.6 — experimental Firefox desktop extension.

The extension runs the MCP handler and outbound OpenAI tunnel client in Firefox. A fixed page adapter uses same-origin ChatGPT endpoints in the explicitly connected personal tab. Session tokens stay in that page. Requested text/metadata/results pass through OpenAI; no developer-operated backend, analytics or persistent conversation database. Optional saved runtime key is password-encrypted locally.

Rebuild the attached source ZIP with `python3 scripts/package_firefox.py` (Python 3 standard library only). JavaScript is copied unchanged; no transpilation, minification or downloads. The unsigned install ZIP is reproducible byte for byte.

Functional review requires private Secure MCP Tunnel access, a dedicated runtime key, a custom ChatGPT app and your own signed-in personal ChatGPT tab. In extension options: unlock/save key → select/connect tab → continue → configure app/Refresh tools → request recent chats. Use disposable chats for writes. Every write requires the exact in-chat confirmation card; preparation alone sends no mutation. No automatic mutation retries or rollback.
